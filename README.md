# Educational Website

Односторінковий навчальний вебсайт, створений у межах лабораторної роботи з використанням HTML, CSS, JavaScript та системи контролю версій Git.

## Опис
Проєкт реалізує адаптивну вебсторінку з базовими вимогами до SEO, доступності та структури контенту.

## Технології
- HTML5
- CSS3
- JavaScript
- Git / GitHub

## Структура проєкту
- `index.html` — основна сторінка сайту
- `style.css` — стилі сайту
- `script.js` — скрипти сайту
- `robots.txt` — правила для пошукових систем
- `sitemap.xml` — карта сайту
